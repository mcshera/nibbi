What these tests prove — and what they don’t

These are isolated procedural animation studies using Nibbi’s ink shader and eye proportions. They test timing, shapes, and face registration, not the app’s state wiring. Each style receives the same cue; scrub maps to each style’s own duration. “Stepped boil” compares edge treatment only, not a full old-engine baseline.

The lab uses real-time WebGL where available, with a simpler Canvas 2D fallback. Performance numbers from a software-rendered browser are not device benchmarks.
